# Software Simplified Technical English

Software Simplified Technical English (SSTE) is a controlled-English standard for
software engineering, development, delivery, operations, and work tracking.

The current edition is **SSTE 1.0 (2026)**. Read the normative specification in
[SSTE-1.0.md](SSTE-1.0.md).

SSTE is designed for:

- requirements, architecture decisions, and design documents;
- user and API documentation;
- source-code comments and review comments;
- command-line procedures and runbooks;
- deployment, DevOps, reliability, and incident communication;
- bug reports, change requests, and other tickets.

The standard is inspired by the controlled-language principles associated with
ASD-STE100, but it is an independent work for the software domain. It does not
copy, replace, or claim conformance with ASD-STE100. “ASD-STE100” and related
names may be trademarks of their respective owners.

## Conformance in one line

Declare the edition, profile, and level, for example:

> This runbook conforms to SSTE 1.0, Procedure profile, Level 2.
